# Simple arena

## Objective

Implement the agreed arena entry, result, inspection, and sharing loop.

## Relevant specification sections

The accepted arena contract supersedes the fixed tournament as the browser entry.
Sections 3, 5, 16, and the machine execution boundaries remain active.

## Files and contracts changed

Changed machine execution, local and remote storage, browser, Worker, and tests.
Added `POST /api/arena`, `GET /api/arena`, and bounded funnel event contracts.
Updated the specification, architecture, README, and Cloudflare runbook.
Recorded the scope decision in [decision 009](../decisions/009-simple-arena.md).

## Decisions and reasons

Keep the fixed tournament for existing clients and historical replays.
Add an arena endpoint with one completed result per immutable strategy.
Select recent completed public strategies once. Fill empty slots with labelled presets.
Use chronological results because entrants face different opponents.
Preserve explicit Logfire access labels and reviewed publication.

## Simplicity review

The requirement needs ten changing opponents and one stored entry per strategy.
The fixed tournament cannot select recent strategies or prevent duplicate arena results.
Existing modules can implement these requirements with explicit functions and storage operations.
New failure modes include duplicate entries, changing opponent sets, and incomplete opponent execution.
Tests must cover storage parity, consent, selection, retries, scoring, and factual browser text.
No new runtime dependency is needed.

## Known limits

No live spending allowance was supplied. New live generation and publication checks remain separate.
The code is not deployed. No new arena trace has completed public publication review.
The existing public example supplies an explicitly separate inspection path.
Public example links can expire or be revoked. The runbook requires rechecking access before promotion.
One invalid participant can stop an entry. No completed result or fabricated choice is stored.
Changing opponents make scores unsuitable for global ranks.
Funnel events count actions, not unique visitors or confirmed social posts.
The X composer contains text and a challenge link. It does not upload an image or publish automatically.
