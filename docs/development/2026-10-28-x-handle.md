# Ask for an X handle

## Objective

Replace the player name prompt with the visitor's X (Twitter) handle.

## Relevant specification sections

The machine creation, simple arena, and section 16.1 contracts apply.

## Files and contracts changed

The browser form requests a handle and explains its public display.
Example buttons change only the strategy.
The existing name field stores the supplied text.

## Decisions and reasons

Remove the preset name and show an example handle as a placeholder.
Preserve the visitor's handle when selecting an example.
Do not require account verification or change existing player records.

## Simplicity review

The existing name field supports this request.
Two direct browser edits suffice.
No abstraction, dependency, or external account lookup is needed.

## Checks run and results

Tracked and unignored file fingerprints matched before and after checks.

## Failures and verified corrections

None.

## Known limits

Handles are supplied by visitors and are not verified.
