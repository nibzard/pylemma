Your player meets another player for ten rounds. Each round, both secretly choose whether to cooperate or betray.

Cooperating together earns more than betraying each other. But betraying someone who cooperates earns you the most.

How this works · Pydantic, Monty, and Logfire

AI generates Python code from your rules once. Monty runs each decision in a fresh sandbox.

Pydantic checks the data. Logfire records the code generation and game execution.

When a reviewed Logfire link is available, you can inspect the information each player received and its returned choice.

The short reasons come from the players' code. They do not prove why the code made a choice.
